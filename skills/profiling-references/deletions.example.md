# Deletions log

One line per profile deletion, **without the person's name**: a log that contains
the names of the deleted defeats the deletions.

Copied to `deletions.md` in your Ghostwriter home by `setup-notion-memory`;
`remove-person` appends to it.

Format:

```
- YYYY-MM-DD · opaque id: P-xxxx · N meetings cleaned, N deleted, N transcripts
  deleted · reason: data subject request | error | other · trash emptied: yes/no
```
