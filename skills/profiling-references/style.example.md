# Your register

**Fill this in before using `compose-message`.** Copy it to `style.md` in your
Ghostwriter home (`~/.ghostwriter/style.md` by default). Without it the agent writes
drafts in *its* register, not yours: correct, polite, and immediately recognisable
as not written by you.

You do not need to describe yourself. What is needed is **real examples**: paste
here 3-5 messages you actually sent, with names changed if you prefer. Write them in
the language you write your messages in.

## How the agent uses it

`compose-message` reads this file before writing. If it is still unfilled, **it says
so**: "draft in my register, not yours — `style.md` is not filled in".

A draft you have to rewrite from scratch every time saves you no time, and this file
is the only thing that separates the two situations.
